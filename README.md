### REKTRUSH AI OS — unified AI operations platform

An in-development platform bringing intelligence, content, community operations, automation, analytics, and administration into one system.

**Architecture:** Next.js/TypeScript frontend · FastAPI backend · Python worker · Supabase/Postgres · pgvector · OpenAI Responses API · Render · GitHub CI

The system is designed around a strict boundary: private integrations and privileged actions run through authenticated backend services with validation and activity logging.

### Shadow — smart-money intelligence engine

An isolated Solana wallet-intelligence and quantitative research system.

- Durable Helius ingestion and idempotent event processing
- Wallet backfills, swap reconstruction, and versioned metrics
- Smart Score, Copy Score, token forensics, and evidence gates
- Relationship analysis and conservative independence grouping
- Structured logs, health checks, retryable workers, and auditable research states
- Explicit separation between intelligence and any future signing/execution service

Shadow currently performs research and intelligence only. It contains no private keys, transaction signing, order routing, or live execution.

5. Verify the exact deployed state—not merely the merged code.
6. Observe production behavior and iterate from evidence.
