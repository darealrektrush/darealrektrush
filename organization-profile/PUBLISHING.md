# CrabStar organization profile

This directory stages public presentation content for CrabStar-Ecosystem. Do not merge it into the personal profile repository as the publication step.

## Publish

1. Create a new **public** repository named `.github` owned by **CrabStar-Ecosystem**. This repository contains only public profile content and design assets; the six implementation repositories remain private.
2. Copy `assets/crabstar-banner.svg` to `assets/crabstar-banner.svg` in the new repository.
3. Copy `profile/README.md` to `profile/README.md` in the new repository. For reliable organization-page rendering, replace the relative banner path with `https://raw.githubusercontent.com/CrabStar-Ecosystem/.github/main/assets/crabstar-banner.svg` once that asset exists.
4. Review the organization overview in desktop and mobile layouts. Check banner loading, table readability and official links before declaring publication complete.

The banner is an original typographic treatment using the personal profile's navy, ocean-blue and muted-gold palette. It does not reproduce or replace an approved CrabStar logo.

No Actions workflow, paid service, license grant, credentials or access changes are included.
